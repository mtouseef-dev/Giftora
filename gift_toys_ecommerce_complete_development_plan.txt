GIFT & TOYS E-COMMERCE WEBSITE — COMPLETE DEVELOPMENT PLAN

PROJECT GOAL
Build a premium, aesthetic, professional Gift & Toys e-commerce website for a real client. The website should have a polished UI/UX, responsive frontend, secure backend, PostgreSQL database, product management, cart, checkout, payment, customer accounts, admin dashboard, and separate deployment.

RECOMMENDED TECH STACK
Frontend:
- Next.js
- TypeScript
- Tailwind CSS
- shadcn/ui
- Framer Motion

Backend:
- Node.js
- Express.js
- TypeScript
- Prisma ORM
- JWT
- bcrypt
- Zod

Database:
- PostgreSQL

Other services:
- Cloudinary — product images
- Razorpay — Indian payments
- GitHub — source control
- Vercel — frontend deployment
- Render — backend deployment

12. IMAGE MANAGEMENT

Use Cloudinary.

Flow:

Admin uploads image
→ Cloudinary
→ Cloudinary returns image URL/public ID
→ Backend saves URL in PostgreSQL

Do not store large image files directly inside PostgreSQL.

13. CART LOGIC

Customer:
Product → Add to Cart → Cart → Checkout

Backend must calculate:
- Current product price
- Quantity
- Subtotal
- Discount
- Shipping
- Tax
- Total

Never trust prices sent from the frontend. The backend should fetch the current price from the database.

14. ORDER STATUS

PENDING

SHIPPED

DELIVERED
CANCELLED

Payment status:

PENDING
PAID
FAILED
REFUNDED

15. RAZORPAY PAYMENT FLOW

Customer
→ Checkout
→ Backend creates order
→ Razorpay Checkout
→ Customer pays
→ Razorpay returns payment information
→ Backend verifies Razorpay signature
→ Payment marked PAID
→ Order marked CONFIRMED

Never allow the frontend alone to declare a payment successful.

Create separate backend project.

Commands:
npm init -y

Create PostgreSQL database.

Run:
npx prisma migrate dev

PHASE 9 — FRONTEND DEPLOYMENT ON VERCEL

1. Push frontend to GitHub.
2. Open Vercel.
3. Import GitHub repository.
4. Configure environment variables.
5. Deploy.

Frontend environment variable:

NEXT_PUBLIC_API_URL=https://your-backend.onrender.com

Production flow:

GitHub
→ Vercel
→ Next.js frontend

PHASE 10 — BACKEND DEPLOYMENT ON RENDER

1. Push backend to GitHub.
2. Open Render.
3. Create New Web Service.
4. Select backend GitHub repository.
5. Configure build command.
6. Configure start command.
7. Add environment variables.
8. Deploy.

Build command:
npm install && npm run build

Start command:
npm start

Backend environment variables:

DATABASE_URL=your_postgresql_connection
JWT_SECRET=your_secret
RAZORPAY_KEY_ID=your_key
RAZORPAY_KEY_SECRET=your_secret
CLOUDINARY_CLOUD_NAME=your_cloud_name
CLOUDINARY_API_KEY=your_api_key
CLOUDINARY_API_SECRET=your_api_secret
FRONTEND_URL=https://yourfrontend.vercel.app
